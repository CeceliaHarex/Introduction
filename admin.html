01 连接你的仓库

只有第一次需要
去生成令牌

三步拿到令牌

  1. 打开 Fine-grained tokens，点 Generate new token。
  2. Repository access 选 Only select repositories，只勾选放网站的这个仓库。
  3. Repository permissions 里找到 Contents，改成 Read and write，生成并复制 github_pat_...。

令牌相当于这个仓库的钥匙，只会保存在你自己的浏览器里，不会出现在网页源码或提交记录中。随时可以在 GitHub 上撤销。

为什么不用密码

这是一个纯静态网站，没有自己的服务器。控制台直接调用 GitHub 的官方接口写文件，所以需要一把只对这个仓库有效的钥匙，而不是你的账号密码。
